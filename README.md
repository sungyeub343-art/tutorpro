# 세종 수학과외

`tutorpro.kr`용 세종특별자치시 수학과외 정적 웹사이트입니다.

## 구성

- 메인 세종 수학과외 페이지
- 세종시 1읍 9면 및 생활권별 동 페이지
- 예비중1·예비중2·예비중3·예비고1·예비고2·예비고3 학습 안내
- 검색엔진용 메타데이터, 구조화 데이터, 사이트맵, robots.txt

## 빌드

```powershell
npm run build
```

생성 결과는 `dist` 폴더에 저장됩니다. `main` 브랜치에 푸시하면 GitHub Actions가 사이트를 빌드해 GitHub Pages로 배포합니다.

## 도메인

가비아 DNS에 다음 레코드를 설정합니다.

| 타입 | 호스트 | 값 |
| --- | --- | --- |
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | sungyeub343-art.github.io. |

GitHub Pages 사용자 지정 도메인은 `tutorpro.kr`이며, DNS 인증서 발급 후 HTTPS 적용을 활성화합니다.
